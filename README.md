Sinch is a cloud communications platform. Its Conversation API is the recommended starting point for messaging, covering SMS, RCS, WhatsApp and other channels through one API, alongside APIs for voice, video, fax, verification and number management. The standalone SMS API is end of sale for new integrations.

**Areas:** Communications · Messaging · SMS · Voice · Verification · CPaaS · Telecommunications · WhatsApp

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Sinch: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
